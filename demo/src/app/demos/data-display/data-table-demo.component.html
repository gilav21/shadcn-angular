{{ t().cardWatchOut }}

  • enableVirtualScroll="auto" won't activate while pagination is on (the default). Set [showPagination]="false" first.
  • enableSubRows and enableRowExpansion are different features: tree children vs. detail panel. Using both adds two expanders per row.
  • Provide a custom [getRowId] when using sub-rows, cell flash, or row selection with server-side data. The default falls back to JSON.stringify.
  • Setting cell, template, and component on the same column? Only one is used (priority: component > template > cell).
  • Editable columns without a valueSetter will mutate your data directly. Provide one for immutable updates.
  • isRowDisabled and disabledRowIds are OR-combined. Both work together.

Pivot mode

A pivot table summarizes a long, flat list into a compact cross-tab. Instead of reading 7 individual sales rows, you collapse them onto a grid: one dimension down the side (rows), another across the top (columns), and a number aggregated in every cell. It answers questions like "total sales per region per product" at a glance.

How it works

  1. Start with flat rows — each has a region, product, quarter and a numeric sales value.
  2. Choose which field becomes the rows, which becomes the columns, and which aggregate (sum/avg/count/min/max) fills the cells.
  3. Call computePivot(data, config) — it groups, aggregates, and returns {{ '{' }} columns, rows {{ '}' }} ready to bind to a data table.

Flip the switch below to compare the raw 7-row source with the pivoted summary — same data, two very different shapes.

Fill handle (drag to fill)

Click a cell (or select a range), then drag the small square at its bottom-right corner down the column. The series is extrapolated Excel-style: numbers step arithmetically, SKU-002 → SKU-003, dates step by the detected interval (the two seed dates are a week apart), and weekday/month names cycle. You can also paste a block copied from Excel/Sheets (Ctrl/⌘+V) onto a focused cell, and undo/redo any fill, paste or inline edit (Ctrl/⌘+Z / Ctrl/⌘+Y). Only columns with a valueSetter are written.

{{ t().sectionRowGrouping }}

Set groupBy to a column's accessorKey to render collapsible group-header rows with per-group aggregation. Click a group header to collapse it. Group headers count toward pagination.

Grouping is mutually exclusive with tree mode (enableSubRows) and virtual scroll — combining them logs a warning and ignores grouping. In grouped mode inline cell editing, cell-range selection, keyboard cell-navigation, and row drag are disabled.
