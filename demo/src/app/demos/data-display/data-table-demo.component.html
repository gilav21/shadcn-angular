{{ t().cardWatchOut }}

  • enableVirtualScroll="auto" won't activate while pagination is on (the default). Set [showPagination]="false" first.
  • enableSubRows and enableRowExpansion are different features: tree children vs. detail panel. Using both adds two expanders per row.
  • Provide a custom [getRowId] when using sub-rows, cell flash, or row selection with server-side data. The default falls back to JSON.stringify.
  • Setting cell, template, and component on the same column? Only one is used (priority: component > template > cell).
  • Editable columns without a valueSetter will mutate your data directly. Provide one for immutable updates.
  • isRowDisabled and disabledRowIds are OR-combined. Both work together.

{{ t().sectionFooterAggregations }}

Columns can define aggregateFn (sum, avg, count, min, max) or a custom footer string/function. The footer row auto-appears when any column has an aggregate.

Conditional formatting

Drive cell styling from the value, declaratively on the ColumnDef — no custom cell components. Amount uses an inline dataBar; Status uses iconSet + cellClassRules.

Range selection actions

Drag-select a block of cells (or click a cell, then shift-click another). A readout bar shows the live Count / Sum / Avg / Min / Max of the selection. Click Chart to emit the range as a chart payload — wired here to a bar chart.

Fill handle (drag to fill)

Click a cell (or select a range), then drag the small square at its bottom-right corner down the column. The series is extrapolated Excel-style: numbers step arithmetically, SKU-002 → SKU-003, dates step by the detected interval (the two seed dates are a week apart), and weekday/month names cycle. You can also paste a block copied from Excel/Sheets (Ctrl/⌘+V) onto a focused cell. Only columns with a valueSetter are written.

{{ t().sectionRowGrouping }}

Set groupBy to a column's accessorKey to render collapsible group-header rows with per-group aggregation. Click a group header to collapse it. Group headers count toward pagination.

Grouping is mutually exclusive with tree mode (enableSubRows) and virtual scroll — combining them logs a warning and ignores grouping. In grouped mode inline cell editing, cell-range selection, keyboard cell-navigation, and row drag are disabled.
