# Replace Lucide-derived icons with our own drawings

Goal: ship `DEFAULT_ICONS` with no third-party drawings, so `THIRD_PARTY_NOTICES.md` and the licence header in `icon.component.ts` can be deleted.

Status: 971 of 971 done. A byte comparison against Lucide 0.300, 0.400, 0.468 and latest found three identical drawings (minus, rss, list-filter); those were changed. The licence header in `icon.component.ts` and `THIRD_PARTY_NOTICES.md` were removed afterwards.

## How the list was built

- 1008 icons in `DEFAULT_ICONS`. 971 have a name that exists in Lucide, so they count as derived. 37 do not and are assumed ours (listed at the end for a provenance check).
- "exact <version>" means the markup equals Lucide's byte for byte in that published version. "modified" means the name matches but the markup differs, so it is probably an edited or unpublished revision and still counts as derived.
- "Feather" marks icons Lucide itself took from Feather (MIT, Cole Bemis).
- Uses = quoted mentions of the name across `packages/components` and `demo/src`, excluding the icon table and the icon gallery list. Most used first.

## Rules for a replacement

1. Draw from the concept, on the 24×24 grid, stroke only, round caps and joins, no fills. The component supplies stroke width and colour.
2. Do not open or paste Lucide markup while drawing. Build from circles, rects, lines and short paths so the construction differs.
3. Check every batch on a rendered contact sheet at 24px and 64px before ticking it.
4. Keep the name, so nothing that uses the icon changes.
5. Tick the box here in the same commit as the new drawing.
